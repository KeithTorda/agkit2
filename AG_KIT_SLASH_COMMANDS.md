# AGKIT2 Workflows

Use natural language or a command. The command selects a helpful procedure; it does not expand scope or authorize unrelated external actions.

| Entry | What to expect |
|---|---|
| `/create` | Inspect needs, choose a suitable foundation and build the new deliverable; UI follows Rule 01 |
| `/enhance` | Complete a scoped change across necessary project boundaries |
| `/brainstorm` | Compare meaningful approaches and recommend a direction |
| `/plan` | Write an executable task plan sized to the work |
| `/proplan` | Link larger-system goals, requirements, design, risk and milestones |
| `/orchestrate` | Coordinate clear ownership and dependencies when parallel work helps |
| `/debug` | Reproduce, distinguish causes, repair the owning layer and verify |
| `/fix-ui` | Repair a render/layout failure while preserving approved direction (browser re-check only on request) |
| `/see` | Inspect actual browser output, relevant styles, console/network and interaction |
| `/see-doc` | Inspect generated-document artifacts and report incomplete checks |
| `/test` | Run or add behavior checks for real contracts and regressions |
| `/verify` | Execute relevant checks and state their actual evidence scope |
| `/review` | Review changed behavior for concrete defects and tradeoffs |
| `/deploy` | Execute the authorized release with appropriate health/recovery evidence |
| `/status` | Read current project state, tasks, changes and uncertainty |
| `/remember` | Save requested durable project guidance |
| `/updatekit --check` | Inspect upstream revisions without pull or installation |
| `/updatekit` | Update a clean compatible source and install with backup |
| `/doctor` | Diagnose the kit's source, installation, active rules and entrypoint without writing |

For difficult reasoning, problem-solving is an optional reference rather than a command ceremony. For visual inspiration, the options include BrewedOps Motion Library at https://brewedops.cloud/motionlibrary/ alongside the user's own references. Neither is a mandatory dependency.
