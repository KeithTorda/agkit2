# AGKIT2 v3.2 — Gaps review and Gemini limitations
Date: 2026-10-27   Status: Draft (waiting for approval)

## Goal
Make the kit work *with* how Gemini 3.x actually behaves in Antigravity, and fill the gaps left after the 3.0/3.1 rebuild.

---

## Part A — Gemini 3.x limitations that affect this kit

| # | Limitation (reported) | Effect on AG Kit | Source |
|---|---|---|---|
| G1 | Instruction following drops on long / complex system prompts; ~78% compliance on nested constraints | Long rules (Rule 01 = 16.9 KB) get partly ignored | Google AI forum: "instruction following drops on complex system prompts" |
| G2 | Forgets earlier instructions late in long sessions | Rules followed at start of a chat, ignored after many turns | same thread |
| G3 | Skips research/plan steps and jumps to code; produces short plans even when told "comprehensive" | `/plan` and `/proplan` come out thin; lead skips breakdown | same thread |
| G4 | Ignores negative rules ("never refactor unrelated code") | Our "Do not / Common mistakes" lists are the weakest part | same thread |
| G5 | Claims it followed rules/used a skill or tool when it did not | "Tests passed", "used skill X" may be false | Antigravity 2.2.1 bug thread |
| G6 | Reads SKILL.md then disregards it | Skills are advisory at best | same bug thread |
| G7 | Less verbose by default; over-analyzes long prompts; follows short direct instructions best; put instructions after long data | Our rules are long prose in places; Rule 07 needs explicit "how much" | Google's Gemini 3 prompting guide (via Tom's Guide) |
| G8 | Rule file limits: per-file truncation (docs: 24,000 bytes; some guides cite 12,000 characters), always-on + global share ~20K tokens | Rule 01 (16.9 KB) is over the 12K-character figure; safe under 24 KB | Antigravity docs `/docs/rules`; antigravitylab |
| G9 | `model_decision` rules load only if the model decides they match | Rule 04 and Rule 05 may never load when they should | Antigravity docs `/docs/rules` |
| G10 | Usage/credit limits on Pro models | Big multi-agent runs burn quota | 9to5google, dataconomy |

**What works best for Gemini (from the same sources):** short, direct rules; one small testable task per chat; the agent writes the plan and you approve it; critical instructions repeated at the end; examples instead of descriptions; checking real tool output instead of trusting reports.

## Part B — Gaps found in the kit

| # | Gap | Why it matters |
|---|---|---|
| K1 | **Rule 01 is 16.9 KB** and long-form | Highest risk of truncation (G8) and of being skimmed (G1). It is your text, so the fix is a compact companion, not an edit. |
| K2 | **No Laravel skill** (only nodejs/python patterns) | Your main backend stack has no dedicated guidance; backend-engineer only has a short stack note. |
| K3 | **No Bootstrap 5 skill** (Tailwind has one) | Your React + Bootstrap admin UI kit has no reference for tokens → `--bs-*`, `data-bs-theme`, components. |
| K4 | **No PH business/compliance skill** | BIR receipts/e-invoicing, VAT/non-VAT, OR/SI numbering, senior/PWD discounts are only mentioned in passing. |
| K5 | **Rule 07 has no code examples** | Gemini follows examples better than descriptions (G7); "template-grade" may still come out plain. Needs ready snippets: navbar, sidebar, KPI card, table toolbar, hero, pricing, empty state, in Bootstrap and Tailwind. |
| K6 | **54 skills were only patched, not rewritten** | Most still read like the old v2.8 prose (long, abstract) — exactly what Gemini skims (G1, G6). |
| K7 | **Negative-heavy lists** in agents/rules | G4: Gemini ignores "don't". Convert to positive "do X instead" lines. |
| K8 | **No end-of-rule recap** | G2/G7: Gemini anchors on what is last. Each rule should end with a 3–5 line "Before you answer, check" block. |
| K9 | **Rule 04/05 are `model_decision`** | G9: may not load. Make Rule 05 always-on (it is small) and give Rule 04 a glob for backend paths + keep model_decision description. |
| K10 | **No proof-of-work in reports** | G5: add to Rule 02 — when claiming a command ran, paste the last lines of its output. |
| K11 | **No per-project template** (`AGENTS.md` / `.agents/rules/project.md`) | Project facts (stack, ERP endpoints, branch names, DB) have no standard home, so every chat re-discovers them. |
| K12 | **No session discipline** | G2/G3: add guidance to kit-core: one milestone per chat; start a new chat after a milestone; plan first, then `/create` per step. |
| K13 | **No real-model test set** | We validated structure, never Gemini behavior. Need `docs/eval/` prompts (UI task, Laravel API, add-on plan, bug fix) with a pass checklist. |
| K14 | **Agent files may not be read** | Antigravity may not load `agents/*.md` as true subagents; the key quality bars should also live in glob rules/skills the model actually receives. |
| K15 | quick-reference is 13 KB | Fine as model_decision, but trim descriptions to keep it scannable. |
