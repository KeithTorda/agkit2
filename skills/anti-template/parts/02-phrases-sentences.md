# 02 — Banned Phrases and Sentence Patterns

Read when: writing or reviewing any sentence, heading, paragraph or list: page copy, docs, emails, release notes, plan files. Single words are in part 01.

## 02.1 Core rules

- One idea per sentence. Cut the second clause if it only repeats the first.
- Delete any adjective you cannot back with a number.
- Replace banned verbs with the literal action.
- No exclamation marks in system text. Keep them only in user-generated content.
- Headings are labels, not slogans or questions.
- Vary sentence length because the content varies, not to create a rhythm.

## 02.2 Openers

Sentences that start a page, section, email or doc and say nothing yet.

| AI pattern | Why it reads as generated | Use instead |
|---|---|---|
| "In today's fast-paced world, ..." | The most recognised model opener | Start with the fact: "The clinic takes appointments online." |
| "In the ever-evolving landscape of X, ..." | Two banned words plus a throat-clear | Delete; start at the second sentence |
| "In the digital age / age of AI, ..." | Era framing adds nothing | Delete |
| "Imagine a world where ..." | Sales daydream | State what the product does now |
| "Picture this: ..." | Colon setup for a story nobody asked for | Delete |
| "Have you ever wondered ...?" | Rhetorical question opener | Answer it as a statement |
| "Are you tired of X?" | Infomercial pattern | Name the problem and the fix in one line: "Paper enrollment forms get lost. Enroll online instead." |
| "Look no further." | Infomercial pattern | Delete |
| "Welcome to {Product}!" | Greeting instead of content | Start with what the page contains; the header already shows the name |
| "Meet {Product}, the ..." | Launch-video voice | "{Product} is a {noun} for {who}." |
| "Introducing {Product}" | Launch-video voice | Same as above, or the release note line |
| "When it comes to X, ..." | Throat-clear | Delete; start with X |
| "X is more than just Y." | Inflated framing | Say what X does |
| "Let's face it: ..." | Fake intimacy | Delete |
| "We all know that ..." | Assumed agreement | State the fact with a source, or delete |
| "It's no secret that ..." | Same | Delete |
| "As we all know, ..." | Same | Delete |
| "Gone are the days when ..." | Nostalgia setup | "You no longer need to X." or delete |
| "It's time to ..." | Call to arms | The instruction itself |
| "So, you want to X?" | Chatty blog opener | Heading "X", then steps |
| "Here at {Company}, we ..." | Brochure voice | Delete "Here at {Company}" |
| "Whether you're a ... or a ..., ..." | Audience-sweep opener | Name the one audience, or delete |

## 02.4 Transitions

| AI pattern | Why it reads as generated | Use instead |
|---|---|---|
| Moreover, Furthermore, Additionally, In addition | Essay glue; the top model tell in prose | Delete; start the sentence with its subject. Use "Also" if a link is needed. |
| It's worth noting that, It is important to note that, Notably, Importantly | Announces a note instead of writing it | Write the note |
| Interestingly, Surprisingly, Remarkably | Tells the reader how to feel | Delete |
| That being said, With that said, Having said that | Filler before a contrast | "But" or delete |
| On the other hand (with no first hand) | Fake contrast | Delete |
| Firstly, Secondly, Thirdly, Lastly, Finally | Essay scaffolding | A numbered list, or plain sentences |
| Needless to say, It goes without saying | Then do not say it | Delete the sentence |
| As mentioned earlier, As previously stated | Repetition flag | Link to the section, or delete |
| Let's take a look at, Let's dive into, Let's explore | Tour-guide voice | A heading and the content |
| Now, ... (at sentence start) | Chatty pacing | Delete |
| In other words, Simply put, To put it simply | Restates the last sentence | Keep the clearer of the two sentences |
| That said, However (every paragraph) | Reflex hedge | Use "however" only for a real contrast, at most once per section |
| Consequently, Thus, Hence, Therefore | Formal glue in UI and marketing | "So", or split the sentence |
| Not only that, but ... | Build-up pattern | State the second fact on its own |
| On top of that, What's more, Better yet | Stacking hype | Delete; list the items |
| Of course, Naturally, Obviously | Assumes agreement | Delete |
| In essence, Essentially, Basically | Summary tic | Delete |
| With this in mind, Bearing this in mind | Filler | Delete |
| This is where X comes in. / That's where X comes in. / Enter X. | Product-reveal cliche | "X does Y." |

## 02.6 Sentence patterns

| AI pattern | Why it reads as generated | Use instead |
|---|---|---|
| Triad slogans: "Fast. Secure. Simple." / "Build. Ship. Scale." / "Create. Collaborate. Ship." | The most copied template tagline shape | One sentence with one fact: "Sales and stock in one app, works offline." |
| "designed to / built to / made to" + abstract benefit | States intent, not result | Present tense result: "Prints BIR-format receipts." |
| "whether you're a ... or a ..." | Audience sweep | Name the one audience, or drop the clause |
| Rhetorical question headings: "Why choose us?", "Ready to get started?", "What makes us different?" | Template section names | Label headings: "Fees", "Requirements", "Contact" |
| "Not just X, but Y" / "Not just a tool, a partner" | Inflation by contrast | State Y plainly, or drop it |
| "It's not about X. It's about Y." | Same pattern, split in two | State Y |
| "X isn't just Y, it's Z." | Same | State Z |
| Parenthetical hype: "(and it's blazing fast!)", "(yes, really!)" | Aside that sells | Delete the parenthesis |
| Em-dash fluff: "— and it just works —", "— from anywhere —" | Dramatic aside | Delete, or a separate sentence with a fact |
| Sentence-initial "And" for drama: "And the best part?" | Setup for a reveal | State the part |
| False scarcity: "Limited spots!", "Only 3 left!" (when untrue) | Pressure; also a consumer-protection risk | Show the real count from the database, or nothing |
| "We" statements about feelings: "We believe in ...", "We're passionate about ...", "We care deeply about ..." | Claims a feeling instead of a practice | The practice with a number |
| Vague social proof: "Loved by thousands", "Trusted by teams worldwide" | Uncheckable | Real count with date and source, or delete |
| Fake specificity: "Built by developers, for developers", "Made by creators, for creators" | Sounds specific, says nothing | Delete |
| Anthropomorphising the product: "{App} understands your needs", "{App} learns and adapts" | Claims intent the software lacks | The rule: "Sorts by the items you order most" |
| Colon reveal: "The result? ...", "The best part? ...", "The catch? ...", "The secret? ..." | Question-then-answer drumroll | State the result directly |
| "Here's how:", "Here's why:", "Here's the thing:" | Drumroll before content | Delete; the content follows anyway |
| "Spoiler: ...", "Plot twist: ..." | Social-media voice | Delete |
| "Think of it as X for Y." / "It's like Uber for X." | Analogy instead of description | Describe it: "Book a barangay hall slot online." |
| "X meets Y." | Pitch-deck formula | Describe the feature set |
| "From X to Y, we've got you covered." | Range sweep plus cliche | List what is covered |
| "No X. No Y. Just Z." | Negative triad | One sentence: "No sign-up needed." |
| "What if you could ...?" / "What if I told you ...?" | Hypothetical sell | "You can ..." |
| "Say goodbye to X and hello to Y." | Infomercial pair | "Y replaces X." |
| "It's time to rethink X." | Call to arms | Delete |
| "Gone are the days of X." | Nostalgia setup | Delete, or "X is no longer needed." |
| "You're not alone." / "We get it." | Fake empathy | Delete; go to the fix |
| "Because you deserve ..." | Flattery | Delete |
| "Everything you need to X." | Coverage claim | List the items |
| "The only X you'll ever need." | Absolute claim | Delete |
| "Built with X, Y and Z" (tech stack as benefit) | Stack is not a user benefit | Move to docs; users need the result |
| "Powered by AI" as the lead | Tech as the benefit | What the user gets |
| "Say more with less." / "Do more with less." | Slogan | Delete |
| "One platform. Endless possibilities." | Slogan with banned words | Delete |
| Double adjectives before every noun: "a fast, secure login" | Padding rhythm | Zero or one adjective, backed by a fact |
| Passive "has been designed to be" chains | Bureaucratic padding | Active present tense |
| "This allows you to / This enables you to" | Indirect | "You can" |
| "Serves as / stands as / acts as" | LLM signature | "is" |
| "It is essential / crucial / important to X" | Lecture voice | Imperative: "Back up the database daily." |
| "Make sure to / Be sure to" (on every step) | Nagging filler | Imperative verb |
| "Please note that ..." | Announces a note | Write the note; use "Note:" once if needed |
| "Feel free to ..." | Permission nobody asked for | Imperative, or delete |
| "Don't hesitate to contact us." | Filler | The contact: "Call 0917 123 4567." |

## 02.7 Rhythm tells

Model text has a regular beat. Readers notice the beat before they notice the words.

| AI pattern | Why it reads as generated | Use instead |
|---|---|---|
| Rule of three everywhere: three adjectives, three bullets, three benefits, three cards | Default list length for models | Use the real count: 2, 4, 7. If there are 2 items, show 2. |
| Three short fragments in a row: "Fast. Clean. Done." | Slogan beat | One full sentence |
| Every sentence 15 to 20 words | Uniform length | Short sentence for the key fact. Long only when the content needs it. |
| Every paragraph 3 sentences | Uniform shape | Paragraph length follows the content; 1 sentence is fine |
| Paired contrast in every paragraph: "Less X, more Y" | Formula | Use once per page at most |
| Alliteration in headings: "Sell smarter, ship sooner" | Copywriter reflex | Plain label |
| Question then answer in consecutive sentences | Drumroll | State the answer |
| Em-dash in every paragraph | Top punctuation tell | Max 1 per 300 words. Use a period or comma instead. |
| Em-dash pairs around an aside: "The app — built for schools — ..." | Dramatic aside | Commas, or cut the aside |
| Semicolons joining two short marketing clauses | Faux-literary | Two sentences |
| Stacking "and" clauses to a crescendo | Build-up rhythm | Split into sentences |
| Mirror sentences: "Your data, your rules." | Slogan formula | Say the rule: "You can export or delete your data at any time." |
| Chiasmus: "We don't just X, we X better." | Slogan formula | Delete |
| Anaphora: three sentences starting with "No more ..." | Speech rhythm | One list |
| Sentence ending on a one-word punch: "It's that. Simple." | Performed drama | Delete |
| Colon before every list inside prose: "Three things: X, Y, Z." | Structuring reflex | Plain sentence or a list |

## 02.8 Heading patterns

| AI pattern | Why it reads as generated | Use instead |
|---|---|---|
| Title Case On Every Heading | Model default for headings | Sentence case: "Payment methods" |
| Question headings: "Why Choose Us?", "How Does It Work?", "Ready To Start?" | Template sections | Label: "Requirements", "Steps", "Fees" |
| "Unlock the Power of X" | Banned verb in heading | "X" |
| "Everything You Need to Know About X" | Blog-bait | "X" or "X: requirements and fees" |
| "The Ultimate Guide to X" | Blog-bait | "X guide" |
| "A Comprehensive Overview of X" | Banned adjective | "X overview", or just "X" |
| "X: A Deep Dive" | Banned phrase | "X in detail", or "X" |
| "Key Features" / "Core Features" | Template section | "Features", or the feature names as headings |
| "Our Story" / "Our Journey" / "Our Mission" | Brochure headings | "About", "History" (if dates follow). See part 05. |
| "What We Offer" / "Our Services" (with 3 icon cards) | Template | "Services", followed by the actual list with fees |
| Emoji in headings: "## 🚀 Getting Started", "## ⚡ Features" | Chat-output formatting | No emoji: "## Install" |
| Heading plus colon subtitle on every section: "Speed: Built for Performance" | Formula | One plain label |
| Heading that repeats the page title | No new information | Delete, or a subsection label |
| Two-word hype heading: "Supercharged Workflows" | Banned words | What the section contains |
| Headings as full sentences with a period | Mixed style | Labels without end punctuation |
| Heading followed by a sentence that restates it | Padding | Start with new information |
| "Introduction" heading on a short page | Essay scaffolding | Delete; the first paragraph is the introduction |
| "Conclusion" / "Final Thoughts" / "Wrapping Up" heading | Essay scaffolding | Delete the section, or "Next steps" with links |
| "Frequently Asked Questions" with 3 questions nobody asked | Template filler | Only real questions from support, or delete. FAQ copy is in part 05. |
| Numbered H2s on a non-sequential page: "1. Speed 2. Security" | Listicle shape | Unnumbered labels |
| Skipped heading levels for size (H1 then H4) | Visual choice using structure | Correct levels; size with CSS. See part 27. |

## 02.9 Paragraph and list shapes

| AI pattern | Why it reads as generated | Use instead |
|---|---|---|
| Intro sentence, three bullets, summary sentence | Default model paragraph | The bullets alone, or a paragraph alone |
| Opening sentence that restates the heading | Echo | Start with the first fact |
| Closing sentence that restates the paragraph | Echo | Delete it |
| Bullets with bolded lead-in and colon: "**Speed:** Pages load fast." | Top list tell | Plain bullets, or a two-column table if every item has a label and a value |
| Every bullet the same length and grammar | Generated symmetry | Bullets can differ; keep them parallel only in verb form |
| Bullets that are full paragraphs | List used for layout | Paragraphs, or shorten bullets to one line |
| One-item list | List reflex | A sentence |
| Nested bullets 3 levels deep | Outline dump | Max 2 levels; otherwise a table or subheadings |
| "Here's a breakdown:" / "Here's a quick overview:" before a list | Drumroll | Delete; the list follows |
| Summary table comparing 2 items | Table reflex | A sentence |
| Pros and cons lists for a decision nobody is making | Balance reflex | State the recommendation and the one reason |
| Every section ending with a CTA sentence | Sales rhythm | One CTA per page area. See part 05. |
| Paragraph of 5+ sentences in UI help text | Wall of text | Max 2 sentences in UI; link to docs |
| Bullets ending with periods in some items only | Inconsistent | Fragments: no period. Full sentences: period on all. |
| "Key points" box repeating the article | Summary reflex | Delete |

## 02.10 Punctuation and formatting tells

| AI pattern | Why it reads as generated | Use instead |
|---|---|---|
| Too many bold words in a paragraph | Chat-output emphasis | Max 1 bold phrase per section, only for a warning or a key value |
| Bold on the first words of every bullet | Chat-output list | Remove bold |
| "!!!" or "!" in system text | Shouting; unprofessional | Period. "!" only in user-generated content. |
| Emoji in headings, labels, toasts or bullets | Chat-output formatting | No emoji. Icons from the icon set if needed. See part 26. |
| Emoji as bullet markers: "✅ Fast", "🔥 Hot" | Chat-output list | Plain bullets or a checkmark icon from the set |
| Emoji at the end of sentences | Social-media voice | Delete |
| Long em-dash asides everywhere | Top model punctuation | Max 1 per 300 words. Commas or periods. |
| Spaced vs unspaced em-dashes mixed | Inconsistent | Pick one style for the project; unspaced is the default in US English |
| Hyphen used as a dash: "Save - then close" | Sloppy | Period, comma, or en dash for ranges |
| Ranges with hyphen: "8-5", "Mon-Fri" | Minor | En dash or "to": "8 AM to 5 PM", "Mon to Fri" |
| Parenthetical hype: "(it's free!)" | Aside that sells | Delete, or state it plainly in the sentence |
| Quote-like fluff: "The future of X" in quotes | Fake quotation | Delete |
| Scare quotes for emphasis: Our "smart" search | Reads as sarcasm | No quotes |
| ALL CAPS feature names: LIGHTNING MODE, TURBO SYNC, SMART ENGINE | Gamer-product voice | Sentence case plain name: "Offline mode", "Auto-sync" |
| ALL CAPS for emphasis in sentences: "Do NOT close this window" | Shouting | Bold "Do not close this window." once, or restructure |
| Trademark symbols on every mention: "Product™" | Legal cargo in UI | Only where legal requires, first mention only |
| Ellipsis for mystery: "And that's just the beginning…" | Cliffhanger | Delete |
| Ellipsis in a label that opens nothing | Misuse | Ellipsis only on a command that opens a dialog for more input: "Save as…" |
| Three dots instead of the ellipsis character | Mixed | Use "…" (U+2026) in UI strings consistently |
| Interrobang or "?!" | Shouting | One mark |
| "&" in running prose | Casual | "and"; "&" only in fixed names or tight labels |
| "and/or" | Legalese | "or", or restate |
| "(s)" for plurals: "1 item(s)" | Lazy pluralisation | Real plural logic. See part 04. |
| Slash lists in prose: "users/admins/mods" | Shorthand | Commas and "and" |
| Colons at the end of headings | Formatting tic | No end punctuation on headings |
| Italics for emphasis in UI | Hard to read, often misused | Plain text; bold once if critical |
| Underline for emphasis | Confused with links | Never underline non-links |
| Curly and straight quotes mixed | Copy-paste from generated text | One style; curly in content, straight in code |
| Oxford comma used in some lists, not others | Inconsistent | Pick one per project and apply it everywhere |
| Two spaces after periods | Old habit | One space |
| Markdown asterisks showing in rendered UI: "**Saved**" | Unrendered model output | Remove the asterisks or render the markdown |
| Horizontal rules between every section | Chat-output formatting | Headings and spacing separate sections |
| Blockquote used for a key point | Chat-output formatting | Plain paragraph; blockquote only for a real quote with a source |
| Hashtags in page copy | Social format outside social | Delete; social posts are in part 08 |
